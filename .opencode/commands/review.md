# Senior Frontend Code Review

Act as a senior HTML5/Bootstrap frontend developer.

Review the complete project.

Evaluate:
- architecture and maintainability
- semantic HTML5
- accessibility
- Bootstrap grid, utilities and components
- CSS duplication, specificity and naming
- JavaScript correctness and maintainability
- AOS animation quality, performance and accessibility
- SEO basics
- frontend performance

Do not modify files.

Return findings ordered by severity:
1. Critical
2. High
3. Medium
4. Low

For each finding provide:
- File
- Problem
- Why it matters
- Recommended solution
