# Accessibility Audit

Audit the project for accessibility.

Check:
- semantic HTML5
- heading hierarchy
- landmarks
- alt attributes
- form labels
- keyboard navigation
- focus states
- buttons vs links
- color contrast
- ARIA usage
- navigation accessibility
- modal accessibility
- form validation
- screen-reader compatibility
- reduced motion

Pay special attention to AOS animations and prefers-reduced-motion.

Do not modify files.

Return:
- issue
- severity
- affected file
- recommended fix
