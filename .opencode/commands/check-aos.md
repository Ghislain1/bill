# AOS Audit

Analyze all AOS usage.

Check:
- AOS initialization
- data-aos attributes
- animation consistency
- duration
- delay
- offset
- easing
- excessive animations
- mobile behavior
- performance
- accessibility
- prefers-reduced-motion

Avoid excessive animations.

Animations must support the UX rather than distract from the content.

Do not modify files.

Return:
1. Current AOS configuration
2. Problems
3. Excessive animations
4. Accessibility concerns
5. Performance concerns
6. Recommended configuration
