# Analyze React/Vite Security

Perform a security analysis of the React/Vite project as senior React project

Check:

* XSS
* dangerouslySetInnerHTML
* unsafe URL handling
* authentication
* authorization assumptions
* token storage
* localStorage/sessionStorage
* exposed secrets
* VITE_* environment variables
* insecure redirects
* dependency vulnerabilities
* sensitive information in frontend code

Pay special attention to the fact that frontend code is publicly accessible.

Classify findings:

* Critical
* High
* Medium
* Low

Do not modify files.
