# SEO Audit

Analyze all HTML pages.

Check:
- title
- meta description
- canonical URL
- viewport
- robots
- Open Graph
- heading hierarchy
- semantic HTML
- links
- image alt attributes
- structured data
- URL structure
- duplicate content
- sitemap
- robots.txt

Do not modify files.

Return:
- current state
- problems
- recommended improvements
