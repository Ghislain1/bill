# Improve Responsive Design

Review and improve responsive behavior.

Target:
- mobile
- tablet
- desktop
- large desktop

Use Bootstrap breakpoints correctly.

Check:
- navbar
- grids
- cards
- images
- typography
- spacing
- buttons
- forms
- tables
- hero sections

Avoid unnecessary custom media queries when Bootstrap utilities can solve the problem.

Preserve the existing visual identity.
