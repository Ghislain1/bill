# Production Readiness

Prepare the project for production.

Verify:

## HTML
- valid HTML5
- semantic markup
- accessibility

## Bootstrap
- correct responsive grid
- consistent utilities
- no invalid classes

## CSS
- no unnecessary duplication
- optimized styles
- maintainable structure

## JavaScript
- no console errors
- no dead code
- correct event handling

## AOS
- animations are purposeful
- no excessive animation
- reduced-motion support

## SEO
- title
- description
- headings
- canonical
- Open Graph
- alt attributes

## Performance
- optimized images
- lazy loading
- efficient resource loading

## Security
Check for:
- unsafe inline scripts
- unsafe HTML injection
- exposed secrets
- insecure external resources

Do not introduce unnecessary dependencies.

Run available validation/build checks.

At the end provide:
- Changes made
- Remaining issues
- Production readiness status
